# 小栗帽桌宠

> 芦毛灰蓝 · 天然呆 · 大胃王 · 温柔陪伴

一只住在你电脑桌面上的赛马娘小栗帽。她会陪你聊天、看看屏幕、吃吃饭团，还会陪你玩 5 个小游戏。附带一个跑在浏览器里的管理面板，用来配置 API、调整外观、管理技能和游戏。

## 快速开始

### 方式一：直接运行 EXE

1. 获取 `小栗帽.exe`
2. 把 `resources/images/` 文件夹放在 EXE 同目录（见[图片素材说明](#图片素材说明)）
3. 双击运行

> ⚠️ **EXE 运行时会自动生成数据文件**
>
> 第一次运行后，数据目录里会自动创建：
> - `.env` — API Key 配置（填入 Key 后产生，Key 以 base64 存储）
> - `chat_history.json` — 聊天记录（上限 2000 条）
> - `settings.json` — 字体 / 间隔 / 记忆轮数 / 宠物大小
> - `pet_state.json` — 饱腹度与活力值（含离线衰减）
> - `companion.json` — 陪伴统计（相处天数、喂食次数等）
> - `facts.json` — 长期记忆
> - `reminders.json` — 安排表
> - `skills_config.json` / `games.json` — 技能与游戏开关
> - `logs/kurumi.log` — 运行日志（1MB 轮转，保留 3 份，管理面板 token 已打码）
>
> 这些是你自己的数据，**请勿随意删除**。分享 EXE 给他人时不要一起打包。
>
> **数据目录的位置**：优先用 EXE / 仓库同级的 `data/`（便携模式）；如果那个位置不可写（例如装在 `Program Files`），会自动回退到 `%APPDATA%\OguriPet`。实际路径在管理面板「设置 → 进程控制」里可以看到，也可以用 `OGURI_DATA_DIR` 环境变量强制指定。

同一路径下重复启动会弹提示，不会开出第二个实例。

### 方式二：从源码运行

```bash
# 安装依赖
pip install -r requirements.txt

# 启动
python main.py
```

仓库自带 `run.bat`（Windows），会自动使用 `.venv` 虚拟环境运行。

## 配置大模型（AI 对话）

不配置也能用——她会用预置文案和你互动。配置后才有真正的对话与看图能力。

**推荐路径**：右键桌宠 → **⚡ 打开管理面板** → **设置** → **API 设置**，选厂商、选模型、填 Key、点「测试连接」、点「保存」。保存后即时生效，无需重启。

| 厂商 | 获取地址 |
|------|---------|
| 火山引擎(豆包) | [console.volcengine.com/ark](https://console.volcengine.com/ark) |
| DeepSeek | [platform.deepseek.com](https://platform.deepseek.com) |
| 通义千问 | [dashscope.console.aliyun.com](https://dashscope.console.aliyun.com) |
| ChatGPT | [platform.openai.com](https://platform.openai.com) |

**关于视觉能力**：只有标注支持视觉的厂商才能"看屏幕"（豆包、通义千问、ChatGPT）。DeepSeek 的 `deepseek-chat` / `deepseek-reasoner` **不支持视觉**，选中后截图参数会被自动忽略，中键看图只会得到普通文字回复。

注意视觉能力在代码里是**按厂商**声明的（`core/ai_providers.py` 的 `supports_vision`），不是按模型。所以选了豆包之后即使挑中 `doubao-pro-32k`、`deepseek-v3` 这类纯文本模型，程序仍会照样把截图发过去，由厂商侧决定是否报错。想要稳定的看图体验，请选 `doubao-seed-1-6-vision-*`、`qwen-vl-*` 或 `gpt-4o`。

## 管理面板

桌宠启动时会顺带起一个**只监听 `127.0.0.1`** 的本地 HTTP 服务，托管一个零框架手写的管理面板。

**打开方式**：右键桌宠 → **⚡ 打开管理面板**，会用默认浏览器打开。启动日志里也会打印带 token 的完整地址。

**安全模型**：
- 仅绑定回环地址，外部无法访问
- 每次启动生成随机 token，页面通过 URL 参数接收后存进 `sessionStorage`，随后从地址栏抹掉
- 请求需带 `X-Management-Token` 头或 `?token=`，SSE 走 query

> ⚠️ 因此**桌宠每次重启，旧页面都会失效**（token 变了）。重启后需要重新从右键菜单打开，不要收藏旧地址。

### 页面一览

| 页面 | 能力 |
|------|------|
| 🏠 **仪表盘** | 饱腹/活力双状态环（实时）、喂饭团、跳转聊天/游戏、**陪伴统计**（相处天数、累计陪伴、喂食次数、开局次数、飞行纪录）、实时日志终端 |
| 💬 **聊天** | 历史时间线（含时间戳）、关键词搜索、网页内直接对话（与桌宠共享同一份记忆与技能）、清空、导出 `.txt` |
| 🎮 **游戏** | 5 个游戏卡片，启用/停用开关，启动/退出游戏（游戏本体仍跑在桌宠窗口上） |
| ⚡ **技能** | 技能列表与启用开关、删除、导入（`.py` / `.zip`）、详情页（参数表 / `SKILL.md` 原文 / **按参数表生成表单手动测试执行**） |
| ⚙️ **设置** | API、宠物大小、字体、聊天记忆轮数、**长期记忆**、系统间隔、**开机自启**、数据目录、重启/退出桌宠 |

**双主题**：左下角圆形按钮可在「深色工业」与「暖色玻璃」之间切换，选择记在 `localStorage`。也支持用 `?theme=light` 链接直接指定。

### 对话输入条

右键 → **💬 对话**，宠物旁边会出现输入条：

- 输入文字按 **回车**（或点「发送」）发送
- 点 **📸** 会同时截图发给 AI
- 不输入文字直接点 **📸** 让 AI 描述当前屏幕
- **✕** 收起输入条

### 自动搭话

小栗帽会自己说话，有两路互不冲突的机制：

- **预设搭话**：固定文案，默认每 120–600 秒一次（设置页可改）
- **AI 搭话**：配置 API 后，默认每 60–300 秒截屏一次，结合上下文主动说一句话（设置页可改）

> 说明：AI 搭话会周期性截取屏幕内容发送给你配置的模型厂商。如果不希望这样，可在设置页把 AI 间隔调得很大。

## 小游戏

进入方式：右键 → **🎮 小游戏** → 选一个；或在管理面板的**游戏**页点「▶ 启动」。

- 游戏期间桌宠的点击/双击/悬停/中键交互会被临时接管（一飞冲天例外：它需要保留拖拽来测抛出速度）
- **空格或点击**是大多数游戏的主要操作，**Esc** 随时退出
- 游戏进行中，右键菜单会多出 **⏹ 退出游戏**
- 屏幕上的计分板可以**拖动**到任意位置
- 退出游戏后桌宠会回到进入游戏前的位置与表情

### 一飞冲天

经典抛高玩法。

1. 进入后小栗帽自动移动到屏幕底部，气泡提示「用力将我抛起来吧！」
2. **按住左键向上甩**，达到阈值后脱手——沿脱手方向抛出，斜抛保留横向分量，撞左右边缘会反弹
3. 空中无视屏幕上下边框，受重力回落，最高点冻结在计分板上
4. 落地后按最高高度给出不同台词

| 高度 | 台词示例 |
|------|---------|
| < 50 米 | 「嗯……是不是最近吃太多变重了……」 |
| 50–200 米 | 「比想象中高了一点！」 |
| 200–350 米 | 「好高！就像冲刺时飞起来的感觉」 |
| 350–500 米 | 「哇啊啊啊啊啊！」 |
| > 500 米 | 「刚才……是不是飞到云上面去了？」 |

高度按 10 像素 = 1 米换算，与冲刺障碍跑一致。手感与鼠标轮询率无关（脱手速度按时间归一化）。

> 这个游戏不会自动结束，想停下按 **Esc** 或用右键菜单的 **⏹ 退出游戏**。

### 接饭团

移动小栗帽接住从天而降的食物。

| 掉落物 | 分值 |
|--------|------|
| 🍙 饭团 | +1 |
| 🍣 寿司 | +3（下落更快，会横向飘移） |
| ⭐ 星星 | +2 |
| 🥕 胡萝卜 | +1 |
| 💢 怒气 | **-2**（要躲开） |

- 操作：**拖动桌宠左右移动**去接；**空格暂停/继续**
- 掉落速度每 10 秒提升一档，最多同时 5 个
- 结算分档：<8「今天的饭团…都在躲着我」/ <12「肚子只有三分饱」/ <16「刚刚好，还能再跑一圈」/ <20「吃得很满足了！」/ ≥20「大丰收！今晚不用做饭了！」

### 大胃王速吃

20 秒内吃完一碗 100 份的饭。

- 操作：**点击屏幕任意处**或**空格**，每点一下吃一口
- 每秒点击 ≥5 次进入**暴食状态**，每口 2 份（每秒有效点击上限 8 次，防连点宏）
- 计分板显示碗的剩余量、剩余时间、当前是否暴食
- 剩余 ≤0 时按剩余时间给不同台词，剩 3 份以内是「唔…差一点点就吃完了」

### 冲刺障碍跑

无尽跑酷，跑得越远越好。

- 操作：**点击或空格起跳**，跳起后受重力回落（起跳初速 -15，重力 0.8）
- 6 类障碍：跨栏、石头、高墙、大树、双栏、飞鸟（双栏需要二连跳，飞鸟在头顶需贴地通过）
- 难度分三阶段：0–30 秒基础障碍 → 30 秒后加入双栏 → 45 秒后加入飞鸟
- 障碍间距按**时间**保证（1.1–2.0 秒），不会因为速度提升而变得无解
- 速度每 10 秒 +0.5（上限 11.0）；硬障碍之后强制给一段喘息
- 结算按距离分档：<100 米「还没热完身…」/ <300「还行，下次更快！」/ <600「有冲刺的感觉了！」/ <1000「像比赛一样兴奋！」/ ≥1000「这是…我的全力冲刺！」

### 钓鱼时机

8 个回合的节奏判定。

- 操作：**点击或空格提竿**
- 浮标在绿色区间内上下摆动，**区间逐回合收窄**（60 → 45 → 30 像素），摆动**逐回合加快**（周期 4.0 → 3.2 → 2.6 秒）
- 每回合浮标的**起始位置都不同**，且不会开局就落在区间里——必须等它摆进来再点
- 判定：正中区间 = `perfect`（🐠 2 分 / 🦐 3 分）；偏离 20 像素内 = `near`（🐟 1 分）；否则空竿
- 结算：≤5「今天的鱼都在睡觉」/ ≤10「晚餐有着落了！」/ ≤14「满载而归！今晚吃鱼！」/ ≥15「这是钓鱼冠军吧！」

## 技能系统

技能放在 `skills/`，每个技能一个目录：

```
skills/<技能目录>/
├── SKILL.md            # YAML frontmatter（name/description）+ 参数表
└── scripts/
    └── helper.py       # 必须导出 execute() 函数
```

`SKILL.md` 的写法：

```markdown
---
name: weather
description: 查询指定城市的当前天气。当用户问天气、温度、多少度、冷不冷、下雨等情况时使用。
---

## Parameters

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| city | string | 是 | 城市名，支持中文（深圳）或英文（shenzhen） |
```

`scripts/helper.py` 里的 `execute` 参数名要与表格对应；额外接收一个 `_pet` 参数即可拿到桌宠对象（用来访问 `schedule_manager` 等）：

```python
def execute(city: str, _pet=None) -> str:
    return f"{city} 今天晴，25℃"
```

**调用方式**：不需要手动触发。技能会作为 Function Calling 的 tool 定义喂给 AI，用户说「深圳天气」时 AI 自己决定调用，拿到结果后用她的语气回答。

### 内置技能

| 技能 | 能力 |
|------|------|
| `weather` | 查天气（数据源 wttr.in，无需 API Key），支持中英文城市名 |
| `schedule` | 安排表：`list` 表格 / `timeline` 时间线 / `today` 今日 / `search` 搜索 / `add` 添加 / `delete` 删除 / `done` 完成 / `archive` 已完成 |

安排表支持一次性、延迟 N 分钟、每天、工作日、周末五种模式，可打 `work`/`personal`/`health` 标签。**单次提醒触发后自动删除，重复提醒（每天/每周）持续有效。**

### 添加自己的技能

两种方式：

1. **手动**：在 `skills/` 下新建目录，按上面的结构写 `SKILL.md` + `scripts/helper.py`，重启桌宠生效。
2. **管理面板**：技能页 →「+ 导入技能」，支持 `.zip`（压缩包内需有 `<目录>/SKILL.md`）或单个 `.py`（会自动生成 `SKILL.md` 骨架并扫描 `execute` 的签名生成参数表）。

写完后可以在技能详情页用**手动测试执行**按参数表填表跑一次，确认返回值正常再交给 AI。

> 安全提醒：技能里的 Python 代码是**直接执行**的，导入第三方技能等于运行陌生代码。

## 状态系统

桌宠有两个隐藏数值，随时间自动变化：

| 数值 | 上限 | 自动变化 | 过低时 |
|------|------|---------|--------|
| 🍙 饱腹度 | 100 | 每分钟 -2 | 台词提示喂饭团 |
| ⚡ 活力值 | 100 | 每分钟 +1 | 打盹动画 + 犯困台词 |

- **喂饭团**（右键菜单或管理面板）：饱腹 +30、活力 +5
- **拖拽小栗帽**：每次消耗 1 点活力
- 鼠标点击不消耗活力
- 低值提醒是**跃迁触发**的：跌破阈值时提示一次，之后 15 分钟内不再重复；恢复到阈值以上 10 点后重新武装

### 关掉也会继续

数值存在 `pet_state.json`，重启时会**按离线时长补算**：离开 30 分钟回来，饱腹度就是实打实掉了 60。超过 12 小时按 12 小时封顶（免得离开一个月回来直接见底，没有层次）。

回来时她会先说话：几小时、几天、一个月以上各有不同台词。

查看状态条：右键 → **📊 查看状态**，双色进度条跟随桌宠移动，5 秒后自动隐藏。

## 长期记忆

聊天记录是滑动窗口，超出后会被丢弃——不处理的话「第七天和第一天体验一样」。长期记忆解决这个：

1. 每积累约 12 条新对话，后台把这一段提炼成关于**你本人**的简短事实（称呼、作息、在做的项目、喜好）
2. 这些事实存在本机 `facts.json`，最多 40 条，超出丢最旧的
3. 每次对话时作为「你记得的训练员」注入人格提示词

**在管理面板的「长期记忆」卡片里**可以：逐条查看、手动添加、逐条删除、一键清空、整体开关。

> **隐私**：全部存在本地，不会上传到除你自己配置的模型厂商之外的任何地方。关掉开关后既不再提炼也不再注入。

## 看屏幕的方式

她不是定时偷看，而是**按情境决定要不要看一眼**：

| 情境 | 行为 |
|------|------|
| 你在忙同一件事超过 50 分钟 | 看了一眼，用这个由头搭话（「同一个窗口待了快一小时」） |
| 深夜（0–5 点） | 提醒该休息 |
| 你离开电脑（系统空闲 ≥5 分钟）或锁屏 | **完全不截屏、不上传** |
| 刚切换窗口 | 先观察，不立刻打扰 |

另外随时可以手动触发：**鼠标中键**点在桌宠身上，或输入条点 **📸**。

两个 AI 间隔在设置页可调（默认预设搭话 120–600 秒、AI 搭话 60–300 秒）。

## 待机行为

空闲时她会自己在桌面上走两步（45–150 秒一次，单次最多 260 像素，不会走出屏幕）。以下情况不会走动：

- 你正在拖她、或她还在惯性滑行
- 她在说话、鼠标悬停在她身上
- 游戏进行中（那时位置归游戏管）
- 刚被你放下或刚说过话的 20 秒内

游戏进行中，预设搭话与 AI 搭话也会一起让位，避免气泡盖住游戏画面、动画抢桌宠位置。

## 打包方法

管理面板前端需要**先构建**，否则打包出来的 EXE 打开管理面板会显示 503：

```bash
cd web && npm install && npm run build && cd ..
pip install pyinstaller
pyinstaller main.spec
```

`main.spec` 已包含打包配置（图片素材 + 技能目录 + `web/dist`）。等价的手工命令：

```bash
pyinstaller --onefile --windowed --icon=icon.ico ^
  --add-data "resources/images;resources/images" ^
  --add-data "skills;skills" ^
  --add-data "web/dist;web/dist" main.py
```

> 打包产物约 38MB。运行日志写入 `data/logs/kurumi.log`。

## 已知限制

- **仅支持 Windows**：透明窗口、点击穿透、DPI 感知、中键截图都依赖 Windows API（`windll` / `ctypes`）。CI 的测试与 lint 在 Linux 上跑，但程序本体不跨平台。
- **仓库换行统一为 LF**：`.gitattributes` 强制 `* text=auto eol=lf`。这是必要的——`core/skill_system/manager.py` 曾在 git 里以二进制 blob 存储（含字面 CR 字节），配合 `core.autocrlf=true` 每次 checkout 都会产生 `\r\r\n`，在此文件上运行 `ruff --fix` 会写出**语法损坏的代码**。修改该文件后请确认 `git ls-files --eol` 显示 `i/lf`。
- **管理面板 token 不落盘**：桌宠重启后旧页面失效，需重新从右键菜单打开。
- **图片素材不能包含透明键色**：Tk 在 Windows 上只能做色键透明，程序会从素材里自动挑一个**没用到的深色**当键色（通常是 `#010203`），所以你的素材里出现纯黑像素是安全的。但如果素材里恰好用了那个色值，那一块会被挖空。
- **测试范围**：`core/ai_client.py`、`ai_providers.py` 与 `ui/` 各窗口模块没有单元测试（分别依赖网络与真实 Tk）。
- **`npm run dev` 不可用**：前端没配 `server.proxy`，而后端是随机端口 + 随机 token，改完前端请用 `npm run build` 后经桌宠托管的页面验证。
- **仅支持主显示器**：`winfo_screenwidth` 只反映主屏，副屏区域无法进入；分辨率变化会在 15 秒内被发现并把桌宠拉回可见区，但不会主动迁移到副屏。

更完整的技术债清单见 [docs/development.md](docs/development.md)。
